# Festival Setup

Festival setup defines the shape of the event before participants and judges start using the system.

## Setup checklist

1. Confirm festival name, dates, branding, and timezone.
2. Create groups or teams.
3. Create categories for participant divisions.
4. Add programmes with category, type, and scoring requirements.
5. Add stages if the festival uses stage scheduling.
6. Configure the scoring policy.
7. Add members and assign roles.

## Recommended practice

Keep category and programme names final before bulk uploads. Changing labels later is possible, but stable names make imports, assignments, schedules, and reports easier to audit.
