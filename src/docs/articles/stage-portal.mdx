# Stage Portal

The Stage Portal helps stage teams coordinate live event flow.

## What it is used for

- See the current schedule.
- Track programme reporting.
- Coordinate stage readiness.
- Keep operators aligned during the event.

## Access

Share the stage portal link only with trusted event staff. It is part of the live operations workflow, not a public visitor page.
