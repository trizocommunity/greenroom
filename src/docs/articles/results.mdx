# Results

Greenroom separates score entry, result publishing, and public display.

## Results workflow

1. Judges or operators enter marks.
2. Admins review programme results.
3. Announcers assign result numbers when needed.
4. Publish results to the public site.
5. Publish standings so visitors see the latest team position.

## After publishing

Published results appear on the festival public site. Results and standings can remain visible according to the festival plan and expiry rules.
