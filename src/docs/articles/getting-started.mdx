# Getting Started

Greenroom helps you run a paperless festival from setup to results publishing.

## Basic workflow

1. Create a festival from the dashboard.
2. Add the festival name, dates, logo, and public details.
3. Choose the plan that matches the event size.
4. Add groups, categories, programmes, and participants.
5. Invite team members if your plan supports them.
6. Launch the public website when the festival is ready.

## Who uses Greenroom

- Owners and admins configure the festival.
- Managers prepare participants, programmes, schedules, and content.
- Judges enter marks during the event.
- Stage operators control live flow and announcements.
- Participants use login links to see assigned programmes and updates.

## Good first setup order

Start with groups and categories, then programmes, then participants. After those are stable, assign participants and build the schedule.
