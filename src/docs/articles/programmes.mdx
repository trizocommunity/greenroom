# Programmes

Programmes are the competitions, performances, or activities in the festival.

## Setup flow

1. Create categories first.
2. Add programmes under the right category.
3. Choose stage or non-stage type.
4. Configure scoring needs.
5. Assign participants.
6. Schedule stage programmes when needed.

## Event readiness

Programmes become ready for event work after required setup is complete. Missing assignments, scoring policy, or schedule details can prevent them from appearing in live workflows.
