# Contact Operators

Contact Greenroom operators when a setup step needs manual help.

## Include these details

- Festival slug.
- Apex domain.
- Screenshot of DNS records.
- Current status shown in Launch Website.
- Browser error, if any.

## When to contact operators

- HTTPS provisioning stays pending after DNS records are correct.
- Vercel asks for verification and the record is not clear.
- A custom subdomain points to the wrong deployment.
- A production festival needs urgent launch help.

Use the Contact page from the public website or your existing Greenroom support channel.
