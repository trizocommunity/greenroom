# Custom Subdomain

A custom subdomain lets a festival use the institution domain while keeping the institution website untouched.

## Example

```text
Festival slug: zenoraev
Apex domain: ahlussuffadars.in
Public URL: https://zenoraev.ahlussuffadars.in
```

## Important rules

- Only PRO institutional festivals can use custom subdomains.
- The institution owner saves, verifies, connects, disconnects, or deletes the apex domain.
- Managers can view status and DNS instructions.
- Each festival host gets HTTPS independently.
- The dashboard always stays on `greenroomfestivals.in`.
- The bare apex and `www` are not festival pages.

## Disconnect vs delete

Disconnect pauses use of the branded URL and shares the Greenroom path URL again. Delete removes the apex from Greenroom and clears verification.
