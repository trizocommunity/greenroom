# Schedule

The schedule organizes programmes and sessions by date, time, and stage.

## Before scheduling

Create stages and programmes first. This keeps the schedule builder focused on timing and flow instead of setup corrections.

## Schedule workflow

1. Open Pre Event Works -> Schedule.
2. Select the day.
3. Add programme entries or sessions.
4. Choose time, stage, and related programme.
5. Review conflicts before the event starts.

Use sessions for non-competition items like opening ceremony, breaks, talks, and announcements.
