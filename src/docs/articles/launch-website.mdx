# Launch Website

The Launch Website screen controls whether the public festival site is visible.

## Public URL behavior

Every festival has a path URL:

```text
https://greenroomfestivals.in/{festivalSlug}
```

PRO institutional festivals can also use a custom subdomain after DNS and HTTPS are ready:

```text
https://{festivalSlug}.{apexDomain}
```

## Launch steps

1. Open Dashboard -> Settings -> Launch Website.
2. Confirm the public site address.
3. Preview the site.
4. Launch when the content is ready.
5. Share the public URL with participants and visitors.

The path URL works even without a custom domain. The branded subdomain appears only after DNS verification and HTTPS provisioning succeed.
